karvi v0.32.0 artifact index #

The release's artifacts are generated beside the source tree and published as the assets of the GitHub release karvi-v0.32.0 (https://github.com/robert-patrick-texas/karvi/releases):

  • karvi-v0.32.0-source-linux-amd64.tar.gz — the complete source with the vendored dependencies, this evidence, and the qualified Linux/amd64 executables (both transports; one build);
  • karvi-v0.32.0-source-linux-amd64.tar.gz.sha256 — its checksum;
  • karvi_0.32.0_amd64.deb — the Debian package built from that bundle: the same four executables in /usr/bin and karvi-sysutil in /usr/sbin, the manual pages, the documents and example configurations under /usr/share/doc/karvi, the service account's template unit karvi-daemon@.service, enabled by nothing until karvi-sysutil daemon install, and the units and timers, cron scripts, crun hook examples, tmpfiles rule, reference configuration, and schemas under /usr/share/karvi, none of them active;
  • karvi_0.32.0_amd64.deb.sha256 — its checksum; and
  • karvi-v0.32.0-artifacts.sha256 — the aggregate delivery checksums, both artifacts.

Every release is installed as new, from its package or its bundle (BUILD-HOWTO.md §3 and §10); no source patch is shipped, and between two public tags the source difference is git diff (karvi-v0.31.1..karvi-v0.32.0). Releases before 0.24.0 were made from the maintainer's private history and their bundles are not published.

The build workflow is BUILD-HOWTO.md; the qualification evidence is release/BUILD-RESULT.md and release/evidence/.
